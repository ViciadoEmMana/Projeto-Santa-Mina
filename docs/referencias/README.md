# Referências e pedidos recebidos

Este arquivo organiza o material disponível que orientou o desenvolvimento.
Os comandos arquivados representam pedidos históricos; podem conter nomes,
regras ou etapas substituídos depois. Para o estado atual, consulte
[o documento Godot](../SANTA_MINA_GODOT.md), [Zeno](../ATUALIZACAO_ZENO.md)
e [o histórico consolidado](../HISTORICO_DESENVOLVIMENTO.md).

- `SANTA_MINA_GODOT_original_recebido.md`: documento original enviado pelo usuário.
- `comandos_recebidos/`: onze pedidos anexados disponíveis, de combate e
  equipamentos até campanha, cartas, interface e a mudança para Zeno.
- `github_antes_importacao/`: README, regras de exclusão e GDD que estavam no
  repositório antes da importação do projeto Godot.

O histórico consolidado resume também decisões fornecidas diretamente no chat.
Não se trata de uma exportação integral da conversa. Logs privados do aplicativo,
credenciais e caches locais não fazem parte do projeto publicado.
